# NSFC Project Landscape Analysis

## When to Use
When you need to understand the NSFC funding landscape for a research direction. Use after retrieving projects via NSFCProjectSearch.

## Analysis Workflow

### Step 1: Data Preparation
- Retrieve 50+ related NSFC projects using NSFCProjectSearch
- Note the score distribution; projects with score >= 15.0 are highly relevant
- Extract statistics: total count, year distribution, project type distribution, top keywords

### Step 2: Funding Focus Analysis
Determine the funding center of gravity:
- Are project titles/abstracts concentrated on specific mechanisms/objects, or general methods/platforms?
- Are high-frequency keywords clustered around a few core issues, or dispersed?
- Are research goals expressed as "explain/verify" or "construct/breakthrough/systematize"?

If most projects share the same problem level, highly overlapping keywords, and similar goal expressions, then a clear funding maintrack exists.

### Step 3: Temporal Evolution
Compare projects across recent 5 years:
- Were early projects more exploratory or problem-divergent?
- Are recent projects more focused on deepening/integrating existing problems?
- Has a new keyword cluster emerged and persisted?

Determine the current phase (exploratory -> convergent -> mature) and its implications.

### Step 4: Maturity and Risk Assessment
Assess these signals:
- Is project count sustained at high levels?
- Are completed projects mostly incremental rather than directional breakthroughs?
- Are new project goal expressions highly similar?

High density + expression homogeneity = field entering maturity/involution.

### Step 5: Strategic Conclusion
Provide a definitive strategic conclusion:
- Direct competition (if the field is still open)
- Clear differentiation entry (if maintrack is crowded)
- Cautious avoidance (if the field is over-saturated)

## Writing Requirements
- Use the "evidence chain" pattern: Observation -> Criterion -> Inference
- Every judgment must be traceable to input data
- No hedging language ("possibly", "to some extent", "tends to")
- No Q&A format, no numbered lists in the main text
- Natural paragraph flow with implicit structure

## Output Format
Write 4 analytical paragraphs covering:
1. Funding focus and core concerns
2. Temporal evolution and phase changes
3. Field maturity and systemic risks
4. Comprehensive strategic judgment (one irreversible conclusion)
